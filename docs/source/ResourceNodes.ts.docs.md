## Nodes
- Meadow Herb Patch: 8 herbs, 2 per gather.
- Old Road Herb Patch: 5 herbs, 1 per gather.
- Ruined Iron Vein: 2 units of the starter iron-key item, requires a Mining Pick.

The iron vein currently uses the existing quest-item placeholder because the starter catalog does not yet define ore as a separate material.
