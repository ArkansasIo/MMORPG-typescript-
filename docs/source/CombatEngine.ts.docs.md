Implements turn order, attack rolls, critical hits, healing actions, status application, periodic burning/poison damage, event logs, and combat state. Uses injectable randomness to make testing deterministic. It is a prototype D20-inspired rule set, not a complete official D&D 5e rules engine. Faction/team victory semantics and richer action economy still need expansion.
